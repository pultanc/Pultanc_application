# Agent Instructions & Project Code Integrity Rules

1. **PRESERVE ALL EXISTING FUNCTIONALITY**: Do not delete, refactor, or alter working functions unless explicitly requested.
2. **SCOPE SURGICAL CHANGES ONLY**: Modify only the specific function, variable, or UI component needed for the user's request.
3. **DO NOT OMIT CODE**: Do not leave placeholders like `// rest of code relies on unchanged functions` or skip necessary import statements.
4. **IF UNSURE, ASK FIRST**: If a requested change impacts another part of the codebase, highlight it before making the change.
